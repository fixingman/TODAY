# Life Exploration skill

Reusable instructions and blank templates for use from any IDE assistant.

## Use from your IDE

Ask your assistant:

> Read life-skill/SKILL.md and follow it for our Life Exploration session. Read references/source-notes.md before using the provisional framework. Use my chosen private exploration folder for state and journal; do not save personal records in this repository.

Paths mentioned in SKILL.md are relative to this life-skill folder. Reading the skill explicitly works even when the IDE does not automatically discover custom skill folders. This folder alone does not register a slash command. INSTALL.md covers optional native Codex and Claude installation.

## Start and continue

Use the approved Dropbox space for personal state and journals, outside this repository. A device-local copy is only a working copy, not a separate canonical record. Choose a separate private data folder there. Ask the assistant to copy templates/state.json as state.json and templates/experiment-journal.md as journal.md there, without overwriting existing records. Tell each IDE assistant where that folder is, or attach the current files when local access is unavailable. The installed skill does not transfer chat memory.

The folder contains no personal journal, credentials, live app integration or scheduled reminders. The four stages and four candidate problems remain provisional until the original source is recovered or you confirm them. See references/today-integration.md for the inspected TODAY architecture and proposed integration boundaries.
