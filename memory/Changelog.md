| **2.61.6** | **Fix: triage "Let go" now commits decision immediately (flow-completion bug).** Root cause: `triageShowReason(id)` only swapped DOM buttons with reason chips — it never set `triageDecisions[id]`. Last task: "Let go" triggers completion immediately (reason = '', acceptable). Non-last tasks: reason chips persist in the decided card row between decisions. |
| **2.61.5** | **Fix: blank screen on wake / PWA background return during focus mode (BUG-071, third recurrence of BUG-004/056 family).** `_forceRepaint` now skips passes when `document.visibilityState === 'hidden'` (no point repainting while re-slept). Both Mac sleep and PWA-backgrounded return go through the same `visibilitychange → _onWake` path. |
