**2.94.0 deployment preparation (2026-10-10):** added the specific Google Calendar `/calendar/v3/` endpoint to Netlify's `connect-src` policy. Calendar's phone-width browser test now serves the actual deployed CSP and mocks requests at the network boundary, including CORS preflight, instead of bypassing CSP through a replaced `fetch`. No credentials, Gmail grants or publishing settings changed. Real Calendar consent/PWA verification remains owed.
