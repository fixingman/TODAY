| **2.17.121** | **Week-grid "best day" dot → composite metric** — the dot in About → This Week previously marked the single most-tasks day, which was **redundant with the bar above it** (bar height already encodes task count). Now it scores each day by a normalized weighted composite: `0.4·(tasks/maxTasks) + 0.35·(focus/maxFocus) + 0.25·(habitsKept/habitsTotal)` — tasks lead (app's primary verb) but a balanced day can out-score a pure task-grind day, so the dot carries signal the bars don't. `_days` now also carries `habitsKept`/`habitsTotal` (live for today via `_activeHabits`, snapshot for past days). Gates preserved: week total tasks ≥ 4, strict single leader (score `*1000` rounded → no dot on a genuine tie), today excluded from winning. Tooltip on the winning dot shows the breakdown (`Your best day · N done · Xm focused · k/t habits`) to mitigate composite opacity. Weights are tunable. |
