| **2.93.11** | **Nightly performance evidence aligned with the deployed app.** The scheduled job now checks out `dev`, requires its version to match the deployed dev HTML, and warms only Chrome's blank renderer before measuring cold page loads; it does not prefetch TODAY assets or relax timing gates. | **2.93.0** | **DreamBank M1 — dreams are kept.** Until now a dream told to the mic got a reading and died on Done. New `assets/dreambank.js` owns everything dream: the reading prompt (moved from `meeting.js`, "someone has just woken up" dropped since a dream can be told days later; dead trailing line removed), a new extraction prompt (images, people, role as JSON), and a local queue `today-dream-queue`. **Loss-proof:** the entry is written from the first chunk that carries a dream, before any Claude call; closing, locking, or killing the app keeps it (next start settles and keeps it). **Night, not recording time:** `meeting-extract` returns `night_hint` (`last_night` · `nights_ago:N` · `weekday:x` · `long_ago` · `unknown`, validated to the same regex as the client) and `lang`; the phone resolves the date ("night of D" = sleep that began the evening of D, so 00:30 and 07:00 both give D−1). **Chunks:** numbered, replies assembled in order, and the capture finalizes only after every chunk answers — `meeting.js` previously awaited only the last, so a slow earlier reply could land after the review (affected meeting tasks too). **Files:** `/Dreams{env}/{night}_{id}.md` in the user's Dropbox, uploaded from capture with `overwrite` via a shared `_dbxPut` primitive (the backup now uses it too; its path, mode, and 401 handling are unchanged) and re-uploaded on every edit; a corrected night renames with `move_v2`; "Don't keep this one" writes a tombstone that fences late replies and retries `delete_v2`. Tests: new `dreambank-unit-test` (night rules incl. 00:30 and weekdays, grounding incl. adversarial and Turkish cases, file format, capture/upload/backoff/rename/tombstone/prune/extraction retries), `meeting-test` dream flows (kept before reading, dream + task, patching, chunk barrier with reversed replies, upload + rename, killed-session dream in Memory), `dropbox-test` backup regression + dream I/O + index merge, `sync-merge-unit-test` index merge.
