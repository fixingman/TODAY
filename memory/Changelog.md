| **2.56.0** | **Splash exit animation: staged letter-group + coda fade.** `_doSplashDismiss` replaced. Exit sequence: (1) `.l:not(.a)` spans ("TO") fade 250ms; (2) 150ms later `.l.a` spans ("DAY") fade 250ms; (3) 50ms later `#splash-date-wrap` fades 200ms; (4) `sBurst` fires at t=300ms; (5) coda lines wrapped in `<span class="splash-coda-line">` via `innerHTML.split('<br>')` and faded sequentially with 100ms stagger, 200ms each; (6) `.poem-author` fades last; (7) `#splash` overlay fades 420ms after last coda line starts. `overlayDelay` is computed: `300 + (n-1)*100 + 200` for n coda lines, 420ms fallback when no coda.
