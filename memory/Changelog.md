# TODAY — Changelog

> Entries older than ~15 versions → `Changelog-archive.md`

| Version | Key change |
|---|---|
| **2.17.74** | **Fix: AI can park a task to Soon on explicit request** — `move_soon` was dropped from the AI action vocabulary in v2.17.25, so asking the assistant "move X to soon" got a refusal even though the handler (`_aiExecute` → `move_soon`) was fully functional (used by deterministic aging chips). Re-added to the system prompt with strict scope: explicit user request only, never proactively suggested (observation-first design intact), manual tasks only (handler guards `manual_` prefix; Trello cards live in Trello). One prompt edit covers both the panel and input-bar paths (shared `_aiCall`). |
| **2.17.73** | **Feat: AI morning nudge** — the morning nudge line (`#morningNudge`) now upgrades its rule-based message with a one-sentence AI observation. `checkMorningNudge` renders the rule-based text instantly, then `_fetchMorningNudgeAI` (mirrors `_fetchWeekReflection`) fires one background call with task names + ages, carried-over count, streak, and yesterday's review. Insight-gated prompt: name something non-obvious if it exists, else state the morning plainly. Response swaps in with a 200ms fade, cached per day (`morning_nudge_ai_YYYY-MM-DD`, pruned on write + cleared at noon). Dismiss-while-fetching guarded. No key / offline / error → rule-based stays, zero regression. |
| **2.17.72** | **Fix: BUG-030b checkmark skipped on rapid back-to-back checks (desktop PWA)** — CSS class approach (`just-checked` + `animationend` listener) replaced with Web Animations API (`svg.animate()`). Each call creates a fresh `Animation` object; no shared state means sequential checks never drop each other. `@keyframes checkPop` and `.just-checked` CSS selector removed. |
| **2.17.71** | **Fix: BUG-030 checkmark animation lags ~30s on iOS PWA open** — `stroke-dashoffset` animation (CPU paint-triggered, blocked during JavaScriptCore JIT warmup window) replaced with `transform + opacity` on the svg element (GPU-composited, runs on compositor thread). Also pre-warms `celebCanvas` Metal GPU pipeline at 2s idle so shader compilation happens before the user's first tap. |
| **2.17.70** | **Fix: localStorage quota failures now visible** — global `localStorage.setItem` wrapper (IIFE after `_logSyncError`) catches `QuotaExceededError` and routes to the red dot with a clear message. Previously these failed silently — tasks/habits could disappear without any indication. |
| **2.17.69** | **Refactor: `_onWake` 200ms debounce** — `visibilitychange` and `window.focus` both fire on desktop PWA restore within ~50ms of each other, running `_onWake` twice (8 repaint passes instead of 4, doubled timers). Added `_lastWakeTime` guard: if `_onWake` is called within 200ms of the previous run, return immediately. 200ms is tight enough to cover the same-event-cluster without blocking genuine rapid wake-sleep-wake cycles (which take >200ms for a human). |
| **2.17.68** | **Fix: BUG-028b completed bar flashes on window return** — v2.17.65's per-pass rAF restore created rapid suppress→restore cycles: each of the 4 `_forceRepaint` passes suppressed then immediately restored, visible as 2–3 quick flashes before the pulse settled. Fix: restore moved out of `_forceRepaint`; animations suppressed across all passes (0–500ms) and restored **once** at 520ms in a single external `rAF` callback. The 1500ms slow-GPU pass receives `skipAnimSuppression=true` so it doesn't suppress already-restored animations. Net result: no flash, no long pause, clean resume. |
| **2.17.67** | **Style: design maintenance** — (1) Added `--text-micro: 9px` token; tokenised 5 hardcoded `9px` uses (`.week-col-day`, `.week-col-focus`, `.sunday-label`, `.ai-provider-badge`, `.error-panel-badge`). (2) Fixed Rule 19 violation: `#sundayBlock` `background` was `rgba(200,240,96,0.04)` → `var(--accent-focus-bg)`. (3) Tokens.md z-index stack fully documented (previously missing: `0` noise, `50` idle companion, `90` `#aiPanel`, `600` splash canvas, `9998/9999` error). |
| **2.17.66** | **Style: removed static week narrative lines** — `#weekNarrative` / `#weekCompare` / `#weekRhythm` (HTML, CSS, and JS blocks) removed from About panel. Rule-based phrases became wallpaper after first reading; the visual grid already shows the week's shape. Sunday AI reflection (`#sundayBlock`) untouched — stays as the one place where a sentence adds genuine value. The weekday-rhythm aggregation pattern (⑥) is removed from the UI but the data (`today_daily_history`) still accumulates; reuse when WEEK companion is built. |
| **2.17.65** | **Fix: BUG-028 true root cause — completed bar static on window return** — `_forceRepaint` suppressed `.complete` animation (`animation:none`) on every wake pass but only restored it after 1500ms. Fix: infinite animations (`.complete`, `.ai-badge`, `.done-star`, etc.) are now restored on the very next `rAF` inside `_forceRepaint` itself — one frame kills the restarted animation, no long hold needed. `.config-panel.open` still stays suppressed until next user-open (BUG-023 pattern unchanged). The 1500ms timeout becomes a plain `_forceRepaint()` call with no special animation restore. |
| **2.17.64** | **Fix: BUG-029 `_aiSendFromInput` undefined** — `ReferenceError` crashed the app when submitting text to AI from the main input bar (✦ tap with text, or Enter while AI panel open). The function was called in two places but never defined. Added it as the natural companion to `_aiAskFromPanel`: same `_aiThread`/`_aiCall`/`_aiRenderResult` pattern, but takes `text` as a parameter instead of reading the in-panel input field. |
| **2.17.63** | **Fix: BUG-028 completion shown a tick late** — `tickFor` decremented to 0, drew "00:00" + a full bar, then scheduled another tick; `completeFor` (`.complete` + "again?" + pulse) only ran ~1s later, so the bar sat full and static before blinking. Now `tickFor` calls `completeFor` in the same tick it reaches zero. Affects all task types (sibling of BUG-025/027). |
| **2.17.62** | **Fix: BUG-027 Trello focus timer** — Trello-specific because the focus `timerEl` + `kbdHint` are children of `#trelloList`, the only list re-rendered every ~7s. (1) Click handler gate `rem < TOTAL` → `rem > 0 && rem < TOTAL`, so a completed (rem=0) session falls through to `start()` and one click begins a fresh countdown instead of opening idle at 25:00. (2) `renderTrello` `stableChildren` now filters to `.task[data-taskid]`, so the timer/hint nodes no longer corrupt the index→sibling repositioning that shuffled rows and disrupted the completed "again?" pulse each sync tick. |
| **2.17.61** | **Habits: 3am grace rollover** — habit day boundary moved from midnight to 3am via `_habitNow()` (`Date.now() - 3h`); `_habitTodayISO()` and `_getHabitDates()` both derive from it, so checking + strip refresh stay in lockstep (avoids the v2.12.74 mismatch). A late check (12:30am) counts toward the day ending. Tasks/streak/focus keep midnight (`_getAppDay`). BUG-010-safe: shifts a Date then derives local YYYY-MM-DD via `_localISO`, never UTC. Known minor edge: a check made between the first post-midnight open and 3am may not be reflected in that day's `today_daily_history` habit snapshot (live strip always correct). |
| **2.17.60** | **Style: week summary lines consistency** — `#weekNarrative` / `#weekCompare` / `#weekRhythm` dropped `font-style: italic` (only italic running text in the About panel; DM Mono renders oblique heavy/wide so it read larger than 12px) and moved `--text-sm2` (12px) → `--text-sm` (11px) + `line-height: 1.5`, matching `.changelog-text`. Muted color now carries the secondary signal. `#weekRhythm` keeps its `opacity` for the quietest tier. |
| **2.17.59** | **Feat: Week summary rhythm + noticing** — (①) `#weekGrid` columns gain activity bars (`.week-col-bar`/`-fill`, height ∝ tasks vs week max, today=`--accent`, others=`--accent-dim`); the week reads as a shape. (②) Single clear standout day gets a quiet `.week-col-dot` (strict max, week total ≥4, not today). (③) Narrative ladder adds a mid-week-rest line ("Steady, with a day to breathe."). (④) New `#weekCompare` line — kind week-over-week vs prior 7 days (more focus / busier / quieter-that's-alright), gated on ≥3 prior known days + clear deltas, else empty. (⑥) New `#weekRhythm` line — "You tend to move most on Tuesdays.", from all history aggregated by weekday, gated on ≥14 days + distinct leader (≥3 samples, ≥1.4× overall avg). WEEK-vision seed. Habit ribbon (⑤) deliberately not included. |
| **2.17.58** | **Feat: Trello checklist badge** — cards with checklists show "N/M ✓" in the task meta row (read-only, option D). `checklists=all` added to cards fetch; `checklist: {done, total}` on task object; `.badge.checklist` muted style. |
| **2.17.57** | **Fix: week narrative reads shape, not totals** — Pattern detection: trend (built momentum / strong start quieter finish), spike day (one day carried most weight), weekend pattern (left it clean / had movement), focus depth (deep when you sat down), or consistency. Replaces count-based observations that were redundant with the grid. |
| **2.17.56** | **Feat: Week reflections** — Rule-based narrative below 7-day grid (picks from: "Showed up every day", "N days in motion", "Xh of deep work", "Best day: X with N done", etc.). Also: About panel title fixed ("TODAY" → "About"); Connections button tooltip no longer mutates to "Trello connected". |
