| **2.27.3** | **Fix: BUG-050 second pass — section headers jittered a few px on mobile scroll.** The v2.27.1 fix measured `sticky-header.getBoundingClientRect().bottom` per scroll event, but iOS moves sticky elements on the compositor thread — the rect reads a few px behind the real position during scroll, and feeding those oscillating values into `--sec-sticky-top` shook the section headers (desktop scrolls on main thread, unaffected). Fix: compute the offset analytically from `scrollY` — `max(0, min(headerHeight, body.offsetHeight − scrollY))` (header is body's first child, body = 100vh, so it stays pinned until `scrollY > bodyHeight − headerHeight` then recedes) — plus rAF-coalesced scroll updates. While pinned the value is a constant, so no style invalidation at all; during departure it decays smoothly from scroll position. |
