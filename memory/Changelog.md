| **2.67.0** | **Feat: per-character bounce animation on task input.** New `assets/task-bounce.js` (IIFE, ~90 lines). Technique: real `<input id="newTask">` keeps native focus/a11y/IME behaviour; its text is hidden via `.has-mirror { color: transparent; caret-color: var(--text) }`. An absolutely-positioned `<div id="newTaskMirror">` overlays it with one `<span>` per character. On each `input` event, the module rebuilds the mirror and applies `.mirror-char-new` (WAAPI `charBounce` keyframe — `translateY(-5px) scale(0.8) → translateY(1px) scale(1.03) → 0`, 120ms ease-out) to the newly inserted character spans only. The animation range is `[animateFrom, animateTo)` so only genuinely new chars bounce — chars that shift position on a mid-word insert stay static. Edge cases: IME (`compositionstart/end`) suppresses per-char animation and syncs the full composed string as a bulk insert; paste/autofill/drop detected via `InputEvent.inputType` + delta-count fallback (`addedCount > 1`) for browsers that omit `inputType` (iOS Safari autofill); programmatic `input.value = ''` calls in `addManual()`, `clearTaskInput()`, and `assistant.js` intercepted via `Object.defineProperty` on the element instance (zero changes to other files); `focus` event re-syncs if value changed while unfocused (meeting.js voice-note placeholder).
