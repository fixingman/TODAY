# TODAY — Changelog

> Entries older than ~20 versions → `Changelog-archive.md`

| Version | Key change |
|---|---|
| **2.49.1** | Polish: `poem-block` `padding-right` increased from 44px to 64px — clears the absolute-positioned share button (right:8px + ~50px wide = left edge at ~58px) on narrow mobile screens where poem lines wrap closer to the right edge. |
| **2.49.0** | **Nav reorganization: TODAY logo opens Memory panel; ✦ star button removed from input bar.** `<h1 id="todayLogo">` gains `onclick="toggleMemory()"` and `title="Memory"`. `.header-left h1` gains `cursor:pointer`, `user-select:none`, `transition:color var(--dur-fast)`; glows `var(--accent)` when the panel is open via `.header-left h1.active`. `$.todayLogo` caches the element; `syncActiveButtons` toggles `.active` on it. `_aiClearBadge()` selector fixed from `.add-ai-btn .ai-badge` (never matched) to `#todayLogo .ai-badge`. Offline/online text-swap handlers on the old button removed — inapplicable to an h1. AI panel active-state add/remove on the old button removed. All 9 `addAiBtn` references cleared. |
| **2.48.4** | **Fix: Trello card 🍅 sessions persist across days (BUG-068).** Added `today_trello_focus_total` — a permanent per-card session counter that lives alongside the existing daily `today_trello_focus` map. The daily map keeps its role as the activity/un-dim signal (BUG-043/064); the total map is what displays on the badge and feeds the triage AI. Syncs cross-device via MAX-merge (no date guard). Pruned in `loadTrello()` when cards leave the board, matching the pattern of `today_trello_firstseen` and `today_trello_lastactive`. |
| **2.48.3** | **Fix: focus ask button — "thinking…" text restored during loading.** Animation overhauled: uses `focusAIBtn.animate()` directly (stored in `_thinkAnim` closure var) with a gentle breath `[{opacity:0.2},{opacity:0.65},{opacity:0.2}]` at 2000ms instead of `_KF_BLINK`'s harsh 0.2→1.0 spike at 1200ms. `_thinkAnim` is explicitly cancelled before the question text is shown (so the question doesn't pulse) and before `_focusResetAI()` restores "✦︎ ask" (so the reset button doesn't pulse). Previous `_breatheAnim` approach was broken: `_breathe()` doesn't return the animation, so `_breatheAnim` stored `undefined` and could never be cancelled. |
| **2.48.2** | **Sunday recap + Monday intention enriched with memory context.** Both `_fetchWeekReflection()` and `_fetchMondayIntention()` now inject `_memoryForAI('weekly')` into the AI prompt — peak hour, behavioral patterns, confirmed inferences, lifespan, task style, suggestion history. System prompt updated to instruct specificity over generics. Old cached values (keyed by date) are unaffected; new memory-enriched versions generate on the next Sunday/Monday. To test today: `localStorage.removeItem('monday_intention_' + new Date().toLocaleDateString('sv'))` in console then reopen About. |
| **2.48.1** | **Memory panel data quality fixes (three issues from live data).** (1) Lifespan humanized: `< 0.5 days` → "most tasks close the same day", `< 1.5` → "about a day to close", otherwise rounded integer. (2) Streak deduplication: SEMANTIC "longest streak" only shows when `best > curStreak`; when they're equal the EPISODIC "on a N-day streak" already covers it. (3) Keyword noise cleaned: stop-word list added (when/what/with/done/that etc.), min word length raised from >3 to >=5 chars, trailing non-alpha stripped at extraction time in `insights.js` and at display time in `renderMemoryPanel()`. |
| **2.48.0** | **Memory abstraction: AI surfaces pending inferences from behavioral data.** On Memory panel open (once/day), `_memoryAbstract()` calls the AI with a compact behavioral summary (completion hours, task lifespan, late-add pattern, top keywords, day-of-week cadence). Returns 1–2 cross-cutting observations as typed inferences (`semantic`/`episodic`/`procedural`), stored with `status:'pending'`. Panel renders pending items in italic with ✓ confirm / ✕ dismiss buttons (Step 4). `_memoryForAI()` in `insights.js` now appends user-confirmed inferences into AI context for morning nudge, focus companion, and triage hints (Step 5). |
| **2.47.0** | **Memory panel: ✦ in task bar now opens Memory, AI ask flow removed.** `addAiBtn` repurposed from `handleBarSubmit()` to `toggleMemory()`. `handleBarSubmit()` removed (dead code). `handleBarKey()` simplified — Enter always calls `addManual()`, Escape still closes AI panel from other surfaces. `toggleClearBtn()` simplified — AI ask-state removed. `_updateBarPlaceholder()` always shows default placeholder. `_aiProactiveSuggestion()` disabled (was badging the now-Memory button). `add-ai-btn` CSS replaced with simple `memory-btn`. `#memoryPanel` added (config-panel pattern). `toggleMemory()`, `renderMemoryPanel()`, `_memoryForget()`, `_memoryClearAll()` added. `appMemory.memory` typed slots (`semantic`, `episodic`, `procedural`) added to schema with migration guard in `insights.js`. Panel shows four-type taxonomy with derived inferences from existing behavioral data. |
| **2.46.1** | **Focus companion question now reads task history.** `_focusAskAI` looks up the task object by `uiTaskId` in `manualTasks` (Trello falls back to `_getTrelloFocus()`). Extracts: `focusSessions` count, age in days, `revived` flag, `zoneChangedAt` (was-deferred). Builds a `_ctx` array of signals and appends them to the user message (`Task: "..."\nContext: N sessions, 7 days old, revived from past`). System prompt updated to a backtick template literal with per-context coaching guidance: first session → done-enough framing; multiple sessions → curious about what's in the way; revived → what changed; long-standing/deferred → gentle check-in. Fixed two syntax errors: apostrophe in CHANGELOG entry, literal newline in single-quoted JS string (both escaped-character hazards per feedback memory). |
| **2.46.0** | **Fix: focus progress fill stays visible during AI question states.** Removed `.focus-timer-fill` from the `.focus-timer.ai-active` fade rule — only `.focus-timer-time` and `#focusPaused` fade out. The fill continues animating behind the answer text (it's `position: absolute` at z-index below the button). |
| **2.45.9** | **Fix: Trello cards due today now carry a signal in the morning nudge prompt.** `dueDate < todayStr` only matched overdue (past) cards. A card due today (`dueDate === todayStr`) got no marker — the AI saw just the card name with no urgency signal. Added `dueDate === todayStr ? ' — due today'` branch so same-day deadlines are explicitly flagged. |
| **2.45.8** | **Fix: focus timer bar no longer changes height when AI question is active.** Removed `max-height: 80px` / `height: auto` expansion from `.focus-timer.ai-active`. Button stays `position: absolute` in all states — in ai-active: `left: var(--space-4); right: var(--space-4)` (spans full bar), `white-space: nowrap; overflow: hidden; text-overflow: ellipsis; text-align: left`. Bar remains exactly 34px. AI prompt shortened from 20→18 words. |
| **2.45.7** | **Fix: triage buttons now render in DM Mono.** `.triage-btn` had no explicit `font-family` — browsers don't inherit font-family onto `<button>` elements from the body, so they fell back to system UI. Added `font-family: var(--font-mono)` to `.triage-btn`. Affects all triage actions (Review, Keep, Let go, Done, Soon). |
| **2.45.6** | **Redesign: thinking state and answer now live inside the timer bar.** When ✦ ask is tapped, the timer bar expands (`max-height: 80px`, inner `height: auto`), fill/time/paused elements fade out, and the button element itself changes content: `✦ ask` → `thinking…` (`.loading` class: xs font, muted color) → question text (sm font, var(--text), normal white-space, tap to dismiss). `_focusAskAI` toggle now checks `timerEl.classList.contains('ai-active')`. `_focusResetAI` no longer references `focusAIQ` (removed). `.focus-ai-q` div and all associated CSS removed. Hints line (`kbdHint`) unchanged — stays showing `space breathe / esc rest`. |
