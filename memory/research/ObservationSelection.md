# Observation Selection — prior art

> Research backing for the 12c observation pool: how other systems pick *which* thing to say
> before any language model is involved. Companion to `design/Personalization.md` (the AI/data
> contract) and `Psychology.md` ("what" not "why").

**Why this file exists.** 12b (v2.78.x) handed the morning nudge a dump of raw `appMemory`
signals and asked the model to judge what mattered. Four prompt revisions could not repair it.
The question "how do you rank candidate observations" turns out to be well studied in three
separate literatures, none of which is prompt engineering. That is itself the headline finding:
**the win here is architectural, not linguistic.**

---

## 1. Pipeline beats end-to-end — the closest thing to a controlled test of 12b vs 12c

Castro Ferreira, van der Lee, van Miltenburg & Krahmer, *"Neural data-to-text generation: A
comparison between pipeline and end-to-end architectures"*, EMNLP 2019 — [arXiv:1908.09022](https://arxiv.org/abs/1908.09022).

Systematically compares generation with explicit intermediate transformation steps against
mapping input straight to text, holding the model class constant. Conclusion: *"having explicit
intermediate steps in the generation process results in better texts than the ones generated by
end-to-end approaches"* — and the pipeline models **generalized better to unseen inputs**.

**What it changes for us:** generalization to unseen input *is* TODAY's production case — every
morning is data the system has never seen. This is the strongest external argument for 12c's
shape, and against expecting a better nudge prompt to fix a selection problem.

**Caveat:** the abstract does not break results out by a named faithfulness/semantic-accuracy
metric, and does not name content selection / ordering / realization as its specific stages.
Read the full paper before citing metric-level claims.

## 2. "Interestingness" is a formalized field — our gates already have names

Geng & Hamilton, *"Interestingness measures for data mining: A survey"*, ACM Computing Surveys,
2006 — [10.1145/1132960.1132963](https://doi.org/10.1145/1132960.1132963).

The field separates **objective** measures (computable from the data alone — coverage,
reliability) from **subjective** ones (novelty, surprisingness, actionability), and holds that
subjective measures **require an explicit model of what the user already knows**. Novelty is not
computable in a vacuum.

**What it changes for us:** our novelty gate needs a knowledge model as a first-class input, not
a prompt instruction. Two things already qualify: `appMemory.spokenLines` (what TODAY has said)
and the fact that `assets/triage.js:118` already prints each task's age. Voice memory (v2.79.0)
was built as prompt text; it belongs in the gate.

## 3. A principled ranking function instead of invented weights

Tang, Han, Yiu, Tang & Zhang, *"Extracting Top-K Insights from Multi-dimensional Data"*,
SIGMOD 2017 — [10.1145/3035918.3035922](https://doi.org/10.1145/3035918.3035922). The lineage
behind Power BI's automatic insights.

Scores a candidate as **impact × significance** — impact being how much of the data the
observation covers, significance being deviation from a null baseline.

**What it changes for us:** gives the candidate builder a defensible ranking function.
Translated: **impact** = how much of the user's month the observation describes; **significance**
= distance from *their own* baseline, never a population's. Self-comparison keeps the claim
conservative, per the AI/data contract.

## 4. Abstention has an evidence base

Pielot, Church & de Oliveira, *"An in-situ study of mobile phone notifications"*, MobileHCI 2014
— [10.1145/2628363.2628364](https://doi.org/10.1145/2628363.2628364). Mehrotra et al., *"My Phone
and Me"*, CHI 2016 — [10.1145/2858036.2858566](https://doi.org/10.1145/2858036.2858566).

Receptivity is governed by volume and timing more than by per-message quality.

**What it changes for us:** silence is a design primitive. Cooldowns and abstention are the
mechanism, not a fallback for when generation fails.

---

## The caution — take the machinery, reject the objective function

This literature optimizes for **interesting**. Top-K Insights ranks explicitly by
*surprisingness*. A surprising claim about a *person* is precisely what 12c's single-reading gate
forbids, and what `Psychology.md`'s "what not why" principle rules out.

**Rule:** rank by impact × deviation-from-own-baseline, then filter through the four gates.
Never rank by surprise. Adopting the algorithm without this substitution walks straight back into
diagnosis — a confident, surprising, unfalsifiable statement about who the user is.
